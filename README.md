## The line

> I know your whole thesis just vanished — but I turned it off and on again, and the little light is green now, so technically we're winning.

The customer's whole thesis just vanished: their desperation is felt, never
explained. The agent is cheerful, useless, and proud of the little green
light — the classic "turn it off and on again" is the setup, and the twist
is that the agent treats a glowing LED as a victory while the customer's
work stays gone. The customer is never the butt of the joke: the agent is.

## Run

```sh
python3 main.py
```

`main.py` (Python 3, standard library only) writes the single line to
`/output/entry.txt` — UTF-8, 139 characters, one line — and reads it back
to confirm the file holds exactly that line. It exits non-zero if the
line ever falls outside the gate's 1–199 characters or is not a single line.
